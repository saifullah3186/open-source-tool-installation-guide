# DFT / ATPG / MBIST

This directory is intentionally educational rather than pretending to provide a universal DFT flow.

Typical DFT work may include:

- scan-chain insertion
- test compression
- ATPG
- fault simulation
- MBIST
- memory repair
- IJTAG/IEEE 1687
- boundary scan/JTAG

Commercial tools such as Tessent provide advanced production DFT flows. Open-source tools can cover parts of the broader design/test ecosystem, but the exact flow depends heavily on the design, libraries, memory models and target technology.

Use this directory to add project-specific DFT examples without making unsupported claims about the base installation.
